# #JW30 — Jasmine's 30th Birthday Trip 🌴

A website for Jasmine's 30th birthday trip to Punta Cana, Dominican Republic.
**10 – 17 September 2026**

## How to deploy on GitHub Pages

1. Create a new GitHub repository (e.g. `jw30`)
2. Upload all files keeping the folder structure:
   ```
   index.html
   images/
     villa-1.avif
     villa-2.avif
     villa-3.avif
     villa-4.avif
     villa-5.avif
     villa-6.avif
   ```
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch and `/ (root)`
5. Click **Save** — your site will be live at `https://yourusername.github.io/jw30`

## Files
- `index.html` — the full website
- `images/` — villa photos used in the carousel
